# Leadership photos

Drop profile photographs here and point `src/data/leadership.ts` at them.

Expected filenames (referenced by the default data):

- `founder.jpg`
- `co-founder.jpg`

Guidelines:

- **Aspect ratio** — 4:5 portrait (e.g. 1000 × 1250). The card crops with
  `object-cover` and centres the subject, so a portrait crop never distorts.
- **Format** — `.jpg`, `.png` or `.webp`. WebP gives the smallest file.
- **Size** — keep each file under ~250 KB.
- **Missing file** — the card falls back to a generated monogram automatically.
  It will never show a broken image, so it is safe to ship before photos exist.
